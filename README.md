# Hollywood Simulator

A persistent, historically grounded (1980–2026) entertainment-industry simulation,
starting with film acting careers. The Python engine owns all numbers and state;
an AI narrator only describes what the engine produces.

- `DESIGN.md` — technical design (architecture, data models, formulas, calibration, phases)
- `prototypes/box_office_sketch.py`, `prototypes/tail_sketch.py` — throwaway, uncalibrated box-office sketches
- `docs/design-v0.2.md` — earlier design, referenced for process and formula detail

Status: design stage. No engine code yet.

```bash
python3 prototypes/box_office_sketch.py
```
